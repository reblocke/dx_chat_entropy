# References

This directory is for lightweight, public reference notes only.

Do not commit private manuscript drafts, internal preprints, reviewer files, meeting notes,
team rosters, publisher PDFs, editable slide decks, or binary reference libraries here.
Use public citations and URLs in `README.md`, `llms.txt`, `CITATION.cff`, or the relevant
workflow documentation instead.

Private supporting materials may exist in the author's local research workspace, but they
are intentionally outside the public branch.
